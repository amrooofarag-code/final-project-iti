# House Price Prediction Project

A end-to-end Machine Learning project for predicting house prices using data analytics, machine learning pipelines, a backend API, and an interactive frontend interface.

## 🚀 Project Structure
- `notebooks/`: Data preprocessing, exploratory data analysis (EDA), and model training scripts.
- `models/`: Trained model files, metadata, and location definitions.
- `backend/`: FastAPI application serving prediction endpoints.
- `frontend/`: Interactive Web User Interface for end users.

## 📌 How to Run
1. Install requirements: `pip install -r requirements.txt`
2. Run backend service: `cd backend && uvicorn main:app --reload`
3. Open frontend in browser.
